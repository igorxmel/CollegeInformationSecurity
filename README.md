# College Information Security

Практические работы по информационной безопасности. Здесь лежат мои решения.

Каждое задание живёт в отдельной папке. Внутри исходная методичка `Task.docx` и папка
`Solution` с отчётом. Первая работа сдавалась в markdown, со второй отчёты оформляются
в `.docx` с титульным листом.

## Задания

- [Task 1. Основные положения закона об информации](Task%201st%20Information%20Law%20Basics)
  Разбор ФЗ-149 «Об информации, информационных технологиях и о защите информации»:
  сфера регулирования, принципы, категории доступа, права и обязанности обладателя
  информации, требования к защите информации в информационных системах.

- [Task 2. Модель угроз и персональные данные](Task%202nd%20Threat%20Model%20and%20Personal%20Data)
  Определения базовых понятий, двадцать шесть угроз из Банка данных ФСТЭК для
  информационной системы интернет-магазина, модель нарушителя по методике ФСТЭК от
  5 февраля 2021 года и разбор основных положений ФЗ-152 «О персональных данных».
